# Southpaw 도구 런처 — 파일럿 직원 안내

**담당자 동행 파일럿용 안내 초안입니다. 참여자·배포일·패키지 승인은 아직 미정입니다.** 승인된 설치 파일은 담당자가 확인해 제공합니다. [추천 파일의 정확한 이름/주소·승인 상태](PILOT_RELEASE_DECISION.ko.md)를 확인하며, 비슷한 이름의 다른 파일을 임의로 설치하지 마세요.

## 무엇을 하는 프로그램인가요?

Southpaw 도구 런처는 사내 제작 도구를 한곳에서 설치·실행·업데이트하는 프로그램입니다. 필요한 TileNamer, ase_viewer, AsepriteTagMaster, Ase-PS Bridge Pro, Pivot_Fixer를 선택해 사용할 수 있습니다. 모든 프로그램을 설치할 필요는 없습니다.

## 처음 설치하기

1. 담당자가 기존 설치 유무와 별도 설치·데이터 위치, 파일의 SHA256을 확인한 뒤 설치 프로그램을 실행합니다. **직원이 혼자 다운로드 파일을 더블클릭하지 마세요.** 현재 추천 후보는 담당자가 데이터 경로를 지정해야 하는 시험용 구성입니다.
2. 마법사에서 담당자가 정한 설치 위치인지 확인한 뒤 설치를 완료합니다. 기존 작업 폴더나 회사 앱 폴더를 선택하지 않습니다. 관리자 실행·보안 설정 변경이 필요하면 진행하지 말고 담당자에게 알립니다.
3. 설치된 시작 메뉴 항목 또는 담당자가 확인한 바로가기로 실행합니다. 현재 추천 후보는 이름에 `설치 시험BDiagSP031113`이 붙을 수 있습니다. 파일럿용 표식이며 일반 직원 배포본과 구분됩니다. 같은 이름의 다른 설치 바로가기를 사용하지 마세요.

확정할 정보: **담당자/연락 수단, 설치일, 내 설치 위치, 내 데이터 위치 — 담당자가 배포 시 기록·안내**. 이 안내서가 직원 이름이나 경로를 임의로 정하지 않습니다.

## 프로그램 설치·업데이트·실행

- 목록에서 필요한 프로그램을 선택하고 설치 상태와 버전을 확인한 뒤 설치합니다. 다운로드·검증·설치 결과가 끝날 때까지 기다립니다.
- 설치된 프로그램은 런처의 실행 버튼으로 엽니다. 앱이 실행 중일 때 업데이트가 보류되면 정상 종료한 뒤 담당자 안내를 따릅니다. 강제 종료하거나 파일을 바꾸지 않습니다.
- 실제 새 버전이 표시되면 담당자와 확인한 뒤 업데이트합니다. 설치 중 오류가 나면 재설치 버튼을 반복 누르지 마세요.
- 인터넷 오류가 있어도 이미 설치된 앱의 정상 로컬 실행은 유지되는 구조입니다. GUI가 열리는지와 업데이트 조회만 실패했는지를 나눠 알려 주세요. 파일을 지워 연결 문제를 해결하지 마세요.

## 런처 자체 업데이트

런처 자신의 새 버전 안내가 있으면 현재/새 버전을 확인하고 담당자 동행으로 승인합니다. 적용 중에는 런처가 닫혔다가 다시 열릴 수 있습니다. Bootstrap이나 버전 폴더를 직접 교체하지 마세요. 예상하지 못한 버전 안내는 담당자에게 먼저 확인합니다.

현재 추천 후보는 최초0.1.3에서 기존 시험 채널의0.1.4로 갱신되는 구성입니다. 이후 임의의 시험 버전을 자동으로 계속 적용하라는 안내가 아닙니다. 회사 앱 업데이트와 런처 자체 업데이트는 별개입니다.

## 문제가 생기면

런처가 열리지 않거나 오류가 나오면 **추가 실행·파일 변경을 멈추고** 발생 시각, 오류 문구/화면, 마지막 작업(최초 실행/업데이트/종료 후 재실행), 창이 남아 있는지를 담당자에게 알려 주세요. 원본 설정·작업 파일은 그대로 둡니다. 토큰·로그 폴더 전체·개인 작업 파일을 채팅에 올리지 마세요.

**과거 Bootstrap 실행 장애의 원인은 아직 미확정이며 검증된 자동 복구 방법은 없습니다.** 담당자가 자료를 보존하고 지원합니다. 직접 관리자 실행, 재설치, journal/current/launcher-home 삭제 또는 버전 EXE 직접 실행으로 우회하지 마세요. 업무가 급하면 사전에 확인한 기존 업무 수단을 사용합니다.

## 제거가 필요하면

현재는 Windows의 설치된 앱/제어판 목록에 런처가 나타나지 않을 수 있습니다. 설치 파일 버전과 실제 런처 버전이 다르게 보일 수도 있으므로 표시 숫자만 보고 잘못 설치됐다고 판단하지 마세요.

제거는 담당자가 설치 위치와 소유권을 확인하고 런처가 정상 종료된 상태에서 진행합니다. 목록에 보이지 않으면 **원래 설치 폴더의 `Uninstall.exe`**가 검증된 직접 제거 경로입니다. 다른 폴더의 제거 파일을 실행하거나 폴더 삭제로 대신하지 않습니다. 실행 중이거나 변경된 파일 때문에 제거가 거부되면 담당자에게 알립니다.

제거 후에도 회사 앱·설정·작업 파일과 런처의 `launcher-home` 저장소는 보존됩니다. 남아 있는 폴더를 오류로 생각해 지우지 마세요. 제거 후 재설치나 장애 복구는 담당자가 판단하며, 제거가 초기화/복구를 보장하는 것은 아닙니다.
